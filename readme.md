# [Modulation Identification] Transformer Model with Dual-Stream Embeddings Achieves a New Breakthrough in SMS Signal Modulation Classification [with Python Code]

The fusion of dual-stream embeddings in a Transformer model achieves a new breakthrough in the modulation classification of short message samples.
Abstract Automated modulation classification (AMC) is a key task in modern communication systems, particularly important under diverse signal conditions and limited data scenarios. Existing Transformer-based AMC models often employ single-stream architectures and uniform input formats, limiting their ability to capture rich signal features. To address this issue, this paper proposes a novel dual-stream network based on Transformer, DTNet, for efficient and accurate modulation classification. DTNet incorporates two core innovations: Firstly, the Scaling Feature Expansion (SFE) module, which converts signals into structured output mappings through scaling functions, then reconstructs them into square matrices with an expansion module, and combines with adaptive filters to integrate response mappings; Secondly, the Convolutional Stream, extracting discriminative features from multi-scale signal representations. Additionally, this paper designs an improved feature embedding method to suit the Transformer architecture, capturing global dependencies and contextual information of the input signals, thereby improving the accuracy of modulation classification. Experimental results show that DTNet performs exceptionally well on benchmark datasets, achieving classification accuracies of 93.4% and 94.4% on RML2016.10A and RML2016.10B datasets respectively, outperforming current state-of-the-art deep learning methods while maintaining lower computational complexity. Introduction In wireless communication systems, dynamic channels adopt adaptive modulation techniques to optimize transmission rates, requiring transmitters and receivers to exchange data related to the modulation scheme, which can lead to protocol overhead. If the receiver can independently identify the modulation type, this overhead can be eliminated, making automatic modulation classification (AMC) a crucial link between signal detection and demodulation, capable of recognizing the modulation format of target signals even when they are affected by noise or interference.
Traditional AMC research is mainly divided into two categories: LB-AMC, which relies on likelihood theory and probability models, achieves high classification accuracy but has a large computational complexity; FB-AMC extracts features from the received signal for classification, achieving high computational efficiency and being more suitable for real-time or resource-constrained scenarios. In recent years, deep learning technology has brought paradigm shifts to AMC, with researchers proposing various deep neural networks to automatically extract signal features, also resulting in mainstream benchmark datasets such as RML2016.10A, RML2016.10B, RML2018.01A.
Currently, CNN, LSTM, GNN, and other networks and fusion architectures have been widely applied in AMC. Researchers have also improved model performance by improving network architecture, introducing attention mechanisms, and optimizing training methods. The Transformer architecture has become a research hotspot due to its ability to capture global dependencies and contextual information of signals. However, existing Transformer-based AMC models significantly degrade in performance on short message signal sample datasets (such as RML2016.10A and RML2016.10B, which only contain 128 complex signal samples).
The modulation classification of short message signals has important practical significance in real-time processing, bandwidth efficiency, and low-latency communication systems. It can accelerate decision speed in dynamic communication environments, optimize bandwidth utilization in resource-constrained channels, but there are still deficiencies in this field of research: existing models for short message signals either have low accuracy (such as the highest accuracy of short-term ResNet is only 61.9%) or introduce excessive computational complexity to improve accuracy. To address this, this paper proposes the DTNet model, specifically designed for feature extraction architectures for short message signal samples, achieving high classification accuracy while maintaining low computational complexity.
Method Introduction: The proposed DTNet model is based on CNN and combines the Transformer architecture. It consists of five core components: SFE module for scale feature extraction, dual-stream embedding, positional embedding, Transformer encoder, and a fully connected classification layer. This model is specifically optimized for modulation classification of short message signals. The core design philosophy involves enriching features + dual-stream integration + lightweight Transformer. The specific module design is as follows:
1  
SFE module: divided into two stages of scale expansion and feature extension, one of the core innovations of DTNet. Firstly, it adaptively scales the raw I/Q signals (L×2) through 1D convolution, batch normalization, and squeeze activation (SE) mechanisms to suppress noise and enhance critical features. Then, it replaces traditional convolution with deep separable convolution, reducing computational complexity while expanding signal features into a L×L matrix, enhancing spatial richness and channel diversity, and preparing for subsequent Transformer feature learning.
2  
Double-flow embedding: simultaneously processes the raw I/Q signals and the output features of the SFE module to form complementary feature fusion. For the raw signals, a 16×2 convolutional patch embedding is used to capture fine-grained temporal features. For the square matrix features output by the SFE, a 32×32 convolutional patch embedding is employed to extract high-level spatial features. The two outputs are then concatenated to form a hybrid feature representation, balancing both the time fidelity of the signals and their spatial abstraction.
3  
Positional Embedding: To supplement positional information for the Transformer encoder, add learnable class tokens before the feature sequence of dual-stream embeddings, and then superimpose learnable positional biases to address the issue that the self-attention mechanism cannot perceive the order of sequences.
4  
Transformer encoder: It consists of alternating multi-head self-attention (MHSA) and an improved dual-branch MLP (DB-MLP). Residual connections and layer normalization are introduced to enhance training stability. The DB-MLP divides the input tokens into two branches for parallel processing, which reduces parameters by 50% compared to traditional single-branch MLPs while improving the model's ability to learn signal features, achieving lightweight design.
Classification layer: The output of the Transformer encoder is mapped to the modulation category space through three fully connected layers. The number of neurons in the last layer matches the number of modulation categories, completing classification.
Model training uses the Adam optimizer with cross-entropy as the loss function, introducing learning rate decay and early stopping mechanisms to prevent overfitting. The model directly takes raw I/Q signals as input without additional preprocessing, using a 70:15:15 training/validation/test data split on the RML2016.10A and RML2016.10B datasets.
Conclusion: This paper proposes a high-precision CNN architecture, DTNet, specifically designed for identifying modulation patterns in various communication signals. While achieving ultra-high classification accuracy, the model maintains fast processing speed and low computational complexity.
The core advantage of DTNet lies in the SFE module design, which rescales the original signal information into a larger matrix representation, generating richer feature mappings, and further expands features by increasing channel count, ultimately forming a square matrix feature; simultaneously, it combines attention mechanisms to capture global dependencies in signals, significantly improving the accuracy of modulation classification. Experimental results show that DTNet achieves recognition accuracies of 93.4% and 94.4% on the benchmark dataset RML2016.10A and RML2016.10B respectively, even maintaining high accuracy rates of 93.6% and 92.7% when the number of signal samples decreases to 96 and 64 respectively, outperforming all current advanced deep learning models.
Furthermore, DTNet features lightweight capabilities (only 5.7 million FLOPs), possesses high-speed inference capabilities on embedded hardware (such as Jetson Orin NX can achieve up to 9000 inferences per second), perfectly fits the real-time and resource-constrained communication system needs, has a high application value in actual scenarios such as dynamic spectrum access and cognitive radio, and provides an efficient solution for automatic modulation classification of short message samples.
